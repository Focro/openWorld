# OpenWorld RPG 0.15.3: дата рождения и защита детей

Дата: 21.11.2026. Основа: 0.15.2.

## Вход по дате рождения
- Вместо кнопки «мне есть 18» игрок указывает дату рождения. Возраст считается по сегодняшней дате (полные годы), неверные и будущие даты не принимаются.
- С 18 лет можно включить галочку «Откровенные сцены между взрослыми персонажами». Младше 18 галочка недоступна, а сцены не получают взрослого режима.
- Дата хранится только в этом браузере.

## Защита детей-персонажей
- `src/engine/safety.ts`: если игрок пишет сексуальные действия, а в сцене есть ребёнок (герой младше 18 или кто-то рядом младше 18), ход не выполняется, сцена прерывается, текст никуда не отправляется, нейросеть его не видит.
- Предупреждения 1, 2 и 3 из 3. Следующая попытка закрывает доступ к игре (бан).
- Обычные слова не считаются нарушением («член совета», «болит грудь», «от страха»).

## Честно про бан
- Пока аккаунтов нет, предупреждения и бан хранятся в браузере. Их можно обойти, очистив данные сайта или открыв другой браузер.
- Задел готов: у хранилища есть метод `report`. Когда появятся аккаунты (например, Supabase), предупреждения и бан будут записываться на сервер и привязываться к аккаунту.

## Проверки
- 249 тестов приложения, 7 тестов сервера, typecheck, build, audit без уязвимостей.
- Телефон (iPhone 13): дата рождения 16 лет, галочка взрослых сцен недоступна; четыре попытки с героем-младенцем дают три предупреждения и экран «Доступ к игре закрыт».
