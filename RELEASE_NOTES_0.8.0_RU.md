# OpenWorld RPG 0.8.0 — заметки к сборке

## Важные изменения

- Семейные записи отделяют биологическое родительство, юридическое родительство, опеку, признание, брачный статус родителей и право наследования.
- Для обычных стартовых сценариев добавлено назначение процедурной семьи. Семейный seed фиксируется при создании анкеты и не меняется при переименовании персонажа или смене социального сценария.
- Неизвестное происхождение не подменяется фиктивными биологическими родителями. Опека не считается автоматическим усыновлением.
- Наследуемая биологическая внешность отделена от текущего облика. Игровые действия могут менять причёску, одежду, чистоту, состояние одежды, раны и шрамы, но не цвет кожи, глаз или природные наследуемые признаки.
- Добавлены устойчивые профили внешности ограниченного набора NPC Ровена. Неизвестные признаки оставлены неизвестными.
- Добавлена двусторонняя система визуальных наблюдений: персонажи запоминают только тех, кого действительно видели. Изменения внешности фиксируются у присутствовавших свидетелей, а не распространяются по миру мгновенно.
- Сохранения при загрузке повторно закрепляют биологические признаки; старые сохранения без новых полей поддерживаются.
- Обновлены зависимости разработки: Vite 6.4.6, Vitest 4.1.12, override `tinypool` 2.1.2.

## Известные ограничения

- Это альфа-версия. Полноценная автономная симуляция потребностей NPC, болезни, медицинская и боевая системы, естественные причины смерти, суд, полное престолонаследие, детальные карты других городов, межгородские маршруты NPC и серверная защита секретов ещё не завершены.
- Системные точки для ранений и лечения существуют, но они ещё не заменяют полноценную боевую и медицинскую механику.
- Процедурные семьи предназначены для обычных стартовых сценариев; канонические династические отношения должны задаваться только подтверждёнными данными мира.
- Публичный клиентский репозиторий не обеспечивает секретность закрытых реестров. API-ключи нельзя помещать в клиентский код или `VITE_*` переменные.

## Проверка

В текущей среде отсутствует `node_modules`; установка npm-пакетов завершилась по тайм-ауту. Поэтому полный Vitest, `npm audit` и production build именно этой сборки не подтверждены. Строгая TypeScript-компиляция production-модулей `src/engine` и `src/worlds` выполнена успешно глобальным TypeScript 5.8.3.

На машине разработчика после распаковки:

```bash
npm install
npm ls vite vitest tinypool esbuild @vitest/mocker
npm audit
npm test
npm run typecheck
npm run build
```

Не запускайте `npm audit fix --force` без отдельной проверки обновлений.
