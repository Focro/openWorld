# Экономия токенов (0.14.0)

Порядок обработки хода:
1. `parseAction` — точные команды.
2. `understandFreeText` (`engine/intent.ts`) — обычная речь по корням слов, без ИИ.
3. Дневной лимит игрока (по умолчанию 50 запросов, «Система»).
4. Кэш намерений (`ai/intentCache.ts`, до 300 записей в localStorage).
5. Только потом — запрос к прокси с коротким пакетом `openworld-intent-v1`.

Пакет намерения: время, возраст, место (`id|имя`), выходы, люди рядом, товары, инвентарь, деньги, разрешённые действия и, только при упоминании, до двух фактов о мире (по 250 символов). Описания мест, биографии и внешность не отправляются.

Стабильные инструкции (`INTENT_INSTRUCTIONS`) одинаковы между ходами — провайдеры кэшируют их (Claude — явно, OpenAI и DeepSeek — автоматически).

Ответ модели — один JSON, лимит 200 токенов.

Идеи взяты из открытых проектов: «лорбуки» KoboldAI/SillyTavern (сведения по ключевым словам), поток памяти Generative Agents (поведение NPC из памяти без вызова модели), парсеры текстовых движков (Inform, Evennia).

Дальше: шире словарь (склонения имён NPC, «поговорить с <имя>»), реплики NPC шаблонами по характеру и памяти, батчинг редких сцен, общий серверный кэш частых намерений.
