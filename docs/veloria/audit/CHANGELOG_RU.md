# Изменения 1.1

- Собраны в один пакет структурированные данные Велории из предыдущего объединённого архива.
- Убраны инженерные исходники движка: пакет посвящён именно миру.
- Добавлен контракт симуляции мира и различие объективного состояния/игрового текста.
- Описаны скрытые поручения, слежка, похищения, передача докладов и проверяемые следы.
- Зафиксировано разделение знаний канона, объективного состояния, личной памяти NPC и слухов.
- Добавлены правила автономной жизни NPC, офлайн-времени и причинных цепочек.
- Добавлены правила персонажа и правдоподобного старта.
- Добавлен аудит известных расхождений; спорные факты не исправлялись молча.

# Изменения рабочей копии 0.7.0 — 21.11.2026

- Рабочая копия объединяет приложение, движок, данные мира Велория, тесты и документацию; старое описание пакета 1.1 выше является историческим журналом, а не описанием текущего архива.
- Укреплена модель семейного происхождения: биологическое родительство, юридическое родительство, опека, признание и наследование хранятся отдельно; семья персонажа получает стабильный seed на этапе анкеты.
- Внешность разделена на биологическую identity и изменяемое состояние; добавлены двусторонние наблюдения внешности игрока и NPC, которые обновляются только при физическом присутствии наблюдателя.
- Добавлены системные точки интеграции ранений/лечения для игрока и NPC; зажившая рана может оставить постоянный шрам, лечение до наступления игрового времени отклоняется.
- Загрузка сохранений повторно замораживает биологические признаки игрока и NPC.
- Обновлены dev-зависимости до исправленной ветки Vitest 4.1.12 и добавлен override tinypool 2.1.2. Полный `npm install`, `npm audit`, `npm test` и production build после обновления ещё должны быть подтверждены на машине с доступом к npm registry.
- Локально подтверждены строгая компиляция TypeScript для движка/данных мира и typecheck тестов с временным объявлением Vitest; выполнены targeted runtime checks для внешности, памяти наблюдателей, семейного seed и сохранений.
