# Народы, дома и духовенство (0.14.0, предложения проекта)

## Облик стран (`populations.ts`)
| Страна | Преобладающий облик | Имена |
|---|---|---|
| Эстран | светлая кожа, русые/каштановые/светлые волосы, серые, голубые, ореховые глаза | западноевропейские (Эдрен, Гарет, Аделина) |
| Элиндор | очень светлая кожа, светлые волосы, голубые/серые/зелёные глаза | северные (Тейво, Ильва, Лаури) |
| Тарвек | светлая или оливковая кожа, тёмные густые волосы, резкие черты | горские (Здеслав, Драгана, Марек) |
| Варент | оливковая или смуглая кожа, тёмные волнистые волосы | приморские (Лоренцо, Кьяра, Беатрис) |
| Сахрад | смуглая кожа, чёрные волосы, тёмные глаза | «имя ибн/бинт отца» (Малик ибн Хасан) |
| Кхарум | кожа от золотистой до смуглой, прямые чёрные волосы, восточноазиатские черты | фамилия впереди (Хань Лян) |

Приезжие: 2–4% в обычных поселениях, больше в портах и столицах, в Варенте больше всех. Правило «внешность определяют родители» остаётся главным; страна задаёт только облик тех, чьих родителей мир не знает.

## Дома
По три новых дома на страну (`proposedHouses.ts`), с `canonStatus: "proposal"`. Их можно переименовать, изменить или удалить без влияния на канон.

## Духовенство (`clergy.ts`)
Для каждой веры: орган управления, резиденция, ступени должностей и три высших служителя. Канонические ограничения из `faiths.ts` соблюдены.
