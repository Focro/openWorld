# OpenWorld — пакет Велории и интеграции 1.3

Это часть полного проекта OpenWorld: здесь собраны литературный канон Велории, структурированные данные мира, правила симуляции и аудит реализации. Само приложение и игровой движок находятся рядом в `src/` и подключены к интерфейсу частично.

## Что внутри

- `VELORIA_WORLD_BIBLE_MASTER_RU.md` — главный литературный канон: география, государства, история, религии, магия, право и социальный порядок.
- `atlas.ts`, `continents.ts` — узлы карты, государства, регионы, маршруты и ограничения старта.
- `nobleHouses.ts`, `lineages.ts` — дворянские дома и родословные.
- `faiths.ts`, `institutions.ts` — шесть религиозных традиций и общественные учреждения.
- `cults.ts`, `blackMarkets.ts`, `hiddenActors.ts` — подпольные организации, теневые сети и скрытые фигуры. Эти записи пока открыты в исходном репозитории и не являются защищёнными секретами.
- `peoples.ts`, `rareIndividuals.ts` — редкие народы и примеры редких персонажей.
- `difficulty.ts`, `lifeBurden.ts` — фиксированные уровни суровости и социальные ограничения.
- `character.ts` — валидация происхождения, статуса, профессии, семейного положения, внешности и старта персонажа.
- `heritage.ts`, `family.ts`, `familyGeneration.ts` и `CHARACTER_HERITAGE_AND_FAMILY_RULES_RU.md` — модель наследования внешности, процедурные семьи обычных персонажей, отдельные биологические/юридические родители и опекуны, признание, даты семейных союзов и правовая неопределённость наследования. Канонические дворянские сценарии пока требуют отдельного согласования.
- `travel.ts` — глобальные маршруты и пошаговое путешествие по игровым дням.
- `world.ts`, `lore.ts` — локальный мир Ровена и календарь Велории; пять основных NPC Ровена получили постоянные стартовые профили внешности.
- `src/engine/appearance.ts` — постоянная биологическая identity и изменяемое состояние внешности; `appearanceObservations` — личные визуальные наблюдения игрока и NPC. Изменения фиксируются только у свидетелей, которые присутствовали при событии.
- `../veloria/` — документы о симуляции, знаниях NPC, тайных операциях, персонаже, социальных порядках и аудитах.

## Приоритет документов

1. Главная Библия мира — источник литературного канона.
2. Технические контракты описывают требуемую причинность, осведомлённость, скрытые действия и автономность NPC.
3. Типизированные файлы `src/worlds/veloria/` — структурированные данные. Если код расходится с Библией, данные необходимо согласовать, а не автоматически переписывать канон.
4. Аудиты отделяют уже реализованное от задуманных, но ещё не подключённых механик.

## Текущая реализация рабочей версии 0.9.0

- Vite/React-приложение запускается через `src/main.tsx`, `index.html` и `vite.config.ts`.
- `src/App.tsx` подключает конструктор персонажа, локальную игровую сессию, хронику, память, сохранение/загрузку JSON и экран выбора после подтверждённой смерти. Для обычных сценариев семья назначается симуляцией; произвольный редактор биологических родителей отсутствует.
- Персонаж собирается с происхождением, статусом, профессией, семьёй, верой, образованием, навыками, биографией, внешностью и ограниченным бюджетом характеристик.
- Обычный старт Велории всегда происходит в Ровене.
- Глобальная карта содержит 30 поселений, 31 маршрут и шесть условных контуров государств. Для 29 поселений кроме Ровена создаются шаблонные локальные карты и три NPC; путешествие из любого поселения требует добраться до ворот/пристани.
- Глобальное путешествие продвигает время по дням, учитывает зимнее закрытие маршрутов, обновляет промежуточные поселения и корректно учитывает каждый день в возрасте героя.
- NPC внутри Ровена тратят время на пешие переходы между точками расписания и не телепортируются мгновенно.

## Ограничения

- Ровен имеет уникальную локальную карту и авторских NPC. В других городах локальные карты и три NPC пока шаблонные; уникальные районы, учреждения, расписания и характеры требуют отдельной разработки.
- Длительности маршрутов — проектные игровые оценки, а не подтверждённые географические измерения. Зимние закрытия уже учитываются; погода, пошлины, транспорт и дорожные события пока не влияют на путешествие.
- Выбор сложности сохраняется в профиле, но числовые коэффициенты ещё не влияют на события.
- При свержении монарха фиксируется политический кризис, но выбор наследника и полноценная симуляция престолонаследия ещё не реализованы.
- NPC не перемещаются между городами и пока не принимают самостоятельные решения. Потребности (сон, еда, жажда, здоровье), автономная работа/семейные обязанности и самостоятельные планы ещё не симулируются. Социальная реакция на заявления игрока пока основана на ключевых фразах и порогах, а не на полном семантическом диалоге и независимом суде.
- Естественное старение героя реализовано через игровое время. Возрастные действия детей, опекуны и обучение ещё не моделируются полностью. Для ран, лечения и шрамов есть системные API и проверки, но полноценная боевая/медицинская система и автоматические причины смерти ещё не реализованы; после подтверждённой смерти можно создать преемника или начать новую версию мира.
- Скрытые реестры находятся в открытых исходниках. До появления приватного backend они не могут считаться секретными.
- API-ключи не принимаются и не хранятся в браузере. Защищённый серверный прокси ещё не создан.

## Проверка

Для полноценной проверки в среде с доступом к npm нужны:

```bash
npm install
npm ls vite vitest tinypool esbuild @vitest/mocker
npm audit
npm test
npm run typecheck
npm run build
```

В среде подготовки `npm install` завершился по тайм-ауту при обращении к npm registry. Поэтому настоящий Vitest-прогон, `npm audit` и production-сборка после обновления зависимостей пока не подтверждены. Строгая компиляция production TypeScript-модулей `src/engine` и `src/worlds` глобальным TypeScript 5.8.3 прошла. В 0.9.0 подготовлено 20 тестовых файлов и 153 тестовых случая, включая географию, импорт сохранений и контекст ИИ. Их фактический прогон ожидает выполнения на машине с доступом к npm registry.
- Речь игрока фиксируется отдельным действием; заявления о другом мире, перерождении и «NPC» вызывают социальную реакцию, слухи и постепенный правовой риск. Повторные заявления при свидетелях из духовенства/стражи могут привести к казни; титул не даёт автоматического иммунитета.
- Попытки создать культ учитываются отдельно от числа сторонников; последователи не появляются автоматически.
- Возраст 0–80 доступен в конструкторе; до пяти лет связная речь заблокирована, а детские заявления имеют меньший социальный вес. Детям младше 16 не назначается взрослая профессия.
- Календарь показывает год KL и день года. Время меняется только игровыми действиями; одно ожидание ограничено 12 часами.


### Новое требование: семья и наследование внешности

Порядок создания персонажа должен начинаться с выбора социального сценария, после чего мир устанавливает родителей и родословную. Ручной выбор произвольных родителей не допускается. Внешность настраивается только после определения доступных семейных признаков. Для королевских наследников и бастардов отдельно учитываются биологическое родство, признание и законность наследования. Подробная спецификация: `CHARACTER_HERITAGE_AND_FAMILY_RULES_RU.md`.
