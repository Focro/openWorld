# Конструктор мира — выбор игрока

Перед началом игры человек выбирает не готовый сюжет, а параметры симуляции.
Параметры должны менять правила генерации мира, а не только оформление страницы.

## Основные настройки

- Жанр: фэнтези, научная фантастика, постапокалипсис, современность, исторический.
- Магия: отсутствует, редкая, распространённая, повсеместная.
- Технологии: примитивные, средневековые, индустриальные, современные, футуристические.
- Сложность: сюжетная, обычная, высокая, смертельно опасная.
- Самостоятельность NPC: низкая, обычная, высокая.
- Экономика: изобилие, сбалансированная, дефицит.
- Насилие: низкий, стандартный, высокий уровень.
- Перманентная смерть: включена/выключена.
- Сверхъестественные явления: включены/выключены.

## Принципы интерфейса

1. Сначала выбор пресета, затем возможность изменить каждую настройку.
2. Показать краткое объяснение последствий каждого параметра.
3. Не навязывать магию: режим «без магии» должен исключать её из генерации,
   предметов, способностей, NPC и событий.
4. «Без магии» и «без сверхъестественного» — отдельные правила, но по умолчанию
   оба выключены в реалистичном сеттинге.
5. Сложность влияет на последствия, ресурсы, лечение, риск, экономику и поведение NPC.
6. Игрок видит итоговую сводку и подтверждает настройки перед генерацией.
7. После начала мира настройки фиксируются в версии мира. Изменение правил позже —
   отдельное осознанное действие, не скрытая подмена.

## Пресеты — только отправная точка

- Низкое фэнтези.
- Высокое фэнтези.
- Средневековье без магии.
- Жёсткое выживание.
- Научная фантастика.

Игрок может изменить любой пресет и сохранить собственный.
