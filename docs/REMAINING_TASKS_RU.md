- **P4:** правила наследования для каждой из шести стран (корона Эстрана, султанат Сахрада, выборный Конклав Тарвека, Торговая Лига Варента, Лига Элиндора, империя Кхарума) — сейчас только Эстран и только как события.
- **P5:** духовенство как NPC в сценах (храмы, обряды рождения и брака по вере).
- **P6:** автономные цели NPC (сейчас есть психология и сплетни, но нет планов).
- **P7:** дворцовая жизнь и дипломатия.
- **P8 дальше:** аккаунты и сервер синхронизации, ответы NPC через ИИ (сейчас ИИ только разбирает намерение игрока), стриминг, хостинг прокси.
- **Платформа:** `src/engine/knowledge.ts` всё ещё импортирует данные Велории — вынести в хук мира, чтобы второй мир подключался без правки движка.
- **Канон, требующий решения автора:** точные даты рождения Марена, Элизы, Орена и день восшествия Элианы (сейчас — допущения проекта); причина смерти матери принца (оставлена неизвестной).

- **Токены:** реплики NPC без ИИ по характеру и памяти; шире словарь разбора; серверный кэш частых намерений.
- **Аккаунты:** вход через Google и почту, облачные сохранения — ждём выбора хостинга.
