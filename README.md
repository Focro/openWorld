## Что это

OpenWorld это платформа для текстовых ролевых игр с многими мирами. Ты пишешь, что делает твой персонаж, обычными словами. Движок проверяет, возможно ли это, и меняет мир по правилам. ИИ понимает твои свободные фразы, а дальше станет рассказчиком: будет описывать сцены и говорить за жителей мира, у каждого свой голос, возраст и характер.

Первый мир называется **Велория**: шесть государств со своим устройством, народами, верой и знатными домами. Можно начать с рождения в обычной семье на окраине Ровена или во дворце, и прожить целую жизнь.

Играть удобнее всего с телефона, прямо в браузере, ничего устанавливать не нужно.

## Чем OpenWorld отличается

- **Мир живёт сам.** У жителей есть расписание, привычки, память и отношения друг с другом. Слухи расходятся и забываются. Пока ты спишь, город продолжает жить.
- **Честные правила.** ИИ не может «нарисовать» тебе золото или победу. Всё, что он предлагает, проходит через движок: время, деньги, возраст, расстояния и законы мира.
- **Жизнь с рождения.** Младенец не говорит, ребёнок не может стать кузнецом, характер складывается из опыта. Вехи развития у каждого свои.
- **Последствия.** Сказал на площади, что ты пришёл из другого мира? Тебя услышали, и это может плохо кончиться. Смерть необратима, но можно продолжить преемником.
- **Свой ключ ИИ.** Каждый игрок подключает свой ключ (DeepSeek, Claude, OpenAI или OpenRouter). Ключ шифруется твоим паролем в браузере и нигде не хранится в открытом виде. Без ключа игра полностью работает на текстовых командах.
- **Бережём токены.** Простые действия движок понимает сам, без запроса к ИИ, поэтому даже бесплатных лимитов хватает надолго.

## Как начать играть

1. Открой [focro.github.io/openWorld](https://focro.github.io/openWorld/) на телефоне или компьютере.
2. Создай персонажа: происхождение, семья, возраст, характер.
3. Пиши действия обычными словами: «иду на рынок», «спрашиваю пекаря про новости».
4. ИИ необязателен. Если хочешь писать совсем свободно, подключи свой ключ в настройках ИИ (пока для этого нужен свой прокси-сервер, см. `server/`).

## Статус

Это ранняя альфа, текущая версия **0.14.0**. Сейчас ИИ переводит свободный текст в действие, а движок проверяет, возможно ли оно. Рассказчик, который описывает сцены и говорит за жителей, это следующий большой шаг, как и общий сервер, чтобы ключ подключался без своего прокси. Подробная жизнь города пока есть только в Ровене, в остальных поселениях базовые точки и жители. Бой, болезни, суды и полноценные диалоги между жителями ещё впереди. Что изменилось в каждой версии, смотри в [CHANGELOG](CHANGELOG.md).

## Для разработчиков

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev      # локальный запуск
npm test         # тесты
npm run build    # сборка для GitHub Pages
```

Стек: React, TypeScript, Vite, Vitest. Движок (`src/engine/`) отделён от миров (`src/worlds/`), чтобы новые миры можно было добавлять, не трогая правила. Серверный прокси для ИИ лежит в `server/`. Подробная документация в [docs/](docs/).
