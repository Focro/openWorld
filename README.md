# OpenWorld — LIVING WORLD RPG (alpha 0.4.0)

Текстовый RPG-симулятор с «живым» миром. Сейчас это **детерминированный движок без ИИ**;
ИИ подключается позже как повествователь и генератор *предложений* действий.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev
npm test
npm run build
```

## Архитектура

| Модуль | Назначение |
| --- | --- |
| `src/engine/types.ts` | Типы мира, состояния, действий |
| `src/engine/world.ts` | Данные стартового мира, расписания NPC |
| `src/engine/rules.ts` | `applyAction` — единственная точка изменения состояния (чистая функция) |
| `src/engine/parse.ts` | Текст игрока → типизированное действие |
| `src/engine/relations.ts` | Отношения NPC к игроку: 4 параметра, плавное изменение |
| `src/engine/gossip.ts` | Слухи между NPC в одной локации, падение уверенности, забывание |
| `src/engine/memory.ts` | Поиск по хронике, «кто что знает» |
| `src/engine/ai.ts` | Граница для ИИ: контексты, проверка предложений, `resolveWithAi` |
| `src/engine/save.ts` | Сохранения с версией формата и ветками таймлайна |
| `src/character.ts` | Правила персонажа: 7 атрибутов, 1–30, сумма ровно 100 |
| `src/schema.ts` | Zod-схемы персонажа и мира |

Принципы:

1. Движок — единственный источник истины. Любое действие проходит проверку правил;
   недопустимое возвращает **то же состояние** без наград и событий.
2. ИИ не меняет состояние. Он видит только контекст (то, что знает игрок / конкретный NPC)
   и возвращает предложение, которое проходит `coerceProposal` и те же правила.
3. Память разделена: хроника мира (правда), память игрока, память каждого NPC. NPC знают только то,
   чему были свидетелями, либо слышали от других (слух с уверенностью < 100%, со временем забывается).
4. Время, расстояния, деньги, инвентарь и цены — системные данные, а не текст.

## Безопасность ключей ИИ

Ключи **не** хранятся в коде, Git, `localStorage` или переменных `VITE_*`. Реальный провайдер
подключать только через серверный прокси (секреты на сервере, минимальные права, маскирование
логов, ротация). Пока прокси нет, в проекте нет ни сетевых вызовов к ИИ, ни полей для ключей.

## Не реализовано

Самостоятельные решения NPC и диалоги, показания страже и шантаж свидетеля, боевая система, база данных и аккаунты, навыки/происхождение/семья/страхи персонажа, редактор географии
и фракций, интерфейс сохранений (формат есть в `src/engine/save.ts`), серверный ИИ-прокси.
