# OpenWorld — LIVING WORLD RPG (alpha 0.14.0)

Текстовый RPG-симулятор с детерминированным игровым ядром. Архитектура ИИ подготовлена: запрос получает ограниченный контекст с источниками, а любое предложенное действие проходит игровые правила. С 0.13.0 ИИ подключается через серверный прокси `server/` (необязательно: без него игра работает на командах).

## Запуск локально

Нужен Node.js 20+.

```bash
npm install
npm run dev
```

Проверка и production-сборка:

```bash
npm test
npm run typecheck
npm run build
npm audit
```

Для локальной production-проверки: `npm run build`, затем `npm run preview`.

## Что уже подключено в интерфейсе

- Велорийский конструктор персонажа: происхождение, социальный статус, профессия, семья, стартовый сценарий, биография, возраст и характеристики.
- Ровен как обязательная стартовая точка первой кампании.
- Выбор фиксированной сложности мира: мирный, сбалансированный или суровый.
- Игровая вкладка с временем, локальными действиями, инвентарём и NPC.
- Физическое время перехода NPC между точками расписания внутри Ровена: пока персонаж идёт, он не считается присутствующим в помещении.
- Глобальная схематическая карта Ардана: 6 государств, 8 регионов, 30 поселений, 31 маршрут и условные контуры государств.
- Для всех 29 поселений за пределами Ровена автоматически создаётся базовая локальная сеть из площади, рынка, постоялого двора и ворот/пристани, а также три постоянных NPC с расписаниями.
- Межгородское путешествие с промежуточными пунктами, сезонным закрытием дорог и учётом каждого дня для возраста персонажа; из Ровена сначала нужно дойти до Южных ворот.
- Хроника мира, память игрока, память NPC и отношения.
- Личность каждого NPC: устойчивый темперамент, ценности, жизненный опыт и индивидуальные привычки; для ключевых персонажей Ровена профили написаны вручную, для массовых NPC используются стабильные ролевые архетипы.
- Привычки укрепляются повторением и ослабевают без подкрепления; NPC постепенно привыкают друг к другу при регулярных встречах. Отношения NPC между собой хранятся отдельно от отношений с игроком.
- Экспорт/импорт JSON-сохранения через интерфейс; импорт поддерживает прежний ветвящийся формат сохранений движка 0.4.0 в демо-мир.
- Естественное старение: каждый полный игровой год увеличивает возраст персонажа и записывается в его личную память.
- После подтверждённой смерти можно создать преемника в продолжающемся мире или начать новую кампанию.
- Речь и жесты — отдельные действия с физическими свидетелями; заявления о другом мире, перерождении или NPC могут вызвать слухи, подозрение, задержание и казнь.
- Попытки создать религию/культ не дают автоматических последователей: сторонники учитываются отдельно.
- Детский персонаж может начать с рождения: до пяти лет доступны жесты, но не связная речь; до 16 лет недоступна взрослая профессия.
- Семейный конструктор назначает процедурную семью обычному персонажу; биологические родители, юридические родители, опекуны, признание и наследование учитываются отдельно. Канонические династии не генерируются произвольно.
- Наследуемая внешность отделена от текущей причёски, одежды, ран и шрамов. Признаки нельзя произвольно менять игровыми командами.
- Двусторонняя визуальная память сохраняет только то, что игрок или NPC действительно наблюдали; удалённые персонажи не узнают об изменениях автоматически.
- Сохранения повторно закрепляют биологическую identity при загрузке; добавлены проверки совместимости старых сохранений.
- Календарь отображает год KL и день года; время и дата включаются в контекст будущего ИИ. Текстовое заявление не может перемотать время, ожидание ограничено 12 часами за действие.
- Подготовлен лексический поиск знаний по каноническим данным: релевантность, синонимы, источники, лимит объёма и разделение публичных/личных знаний NPC.

## Ограничения текущей альфы

Глобальное путешествие уже продвигает время по дням и фиксирует путь в хронике. При этом детальная уличная симуляция пока подключена только для Ровена. В остальных городах доступны шаблонные локальные точки и три базовых NPC; уникальные уличные карты, учреждения, индивидуальные NPC и самостоятельная жизнь поселений ещё требуют проработки. Длительность маршрутов — проектные игровые оценки из атласа, а не подтверждённые геодезические расстояния. Сезонные закрытия перевалов уже учитываются; погода, дорожные происшествия, пошлины, транспорт, снабжение и автономные караваны ещё не влияют на путешествие.

Также не завершены: полноценные автономные решения NPC, содержательные диалоги между ними и их перемещение между городами (внутригородские переходы уже учитывают время), полноценные диалоги и судебное расследование (текущая реакция на речь основана на ключевых фразах и порогах), возрастные действия детей и опекуны, престолонаследие, боевая система, болезни, лечение, травмы и автоматические триггеры смерти, полноценный генератор миров, backend, аккаунты и защищённый ИИ-прокси.

## Безопасность ключей ИИ

ИИ подключается только через серверный прокси `server/ai-proxy.mjs`: ключ сервера живёт в переменной окружения хостинга, а не в `VITE_*`, исходниках или git. Игрок может указать свой ключ: он шифруется в браузере его паролем (PBKDF2 + AES-GCM), пароль не хранится, расшифрованный ключ живёт только в памяти вкладки и уходит только по HTTPS или на localhost. Модель лишь предлагает действие, движок проверяет его по правилам и возрасту. Подробно: `docs/AI_PROXY_AND_KEYS_RU.md`. Реестры скрытых фигур и культов по-прежнему лежат в открытых исходниках и не являются настоящими секретами до появления приватного backend.

## GitHub Pages

Vite использует `base: "/openWorld/"` для репозитория `Focro/openWorld`. Workflow в `.github/workflows/deploy.yml` устанавливает зависимости, запускает тесты и production-сборку, затем публикует каталог `dist`. В GitHub нужно включить **Settings → Pages → Build and deployment → GitHub Actions**.

В обычных кампаниях второй принц материализуется как NPC при дворе.
