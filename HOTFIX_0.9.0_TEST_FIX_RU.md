# Hotfix OpenWorld RPG 0.9.0 — исправления четырёх тестов

Исправления после пользовательского прогона Vitest (21.11.2026):

1. `src/engine/appearance.ts`: восстановлены совместимые русские подписи наследуемых признаков. Цвет глаз остаётся читаемым в наблюдениях NPC и игрока; природный цвет волос снова обозначается как «природные волосы».
2. `src/worlds/veloria/family.ts`: если закон требует юридическое родительство, по умолчанию требуется подтверждение двух родителей. Частично известный юридический статус возвращает `undetermined`, а не `eligible`. Если закон явно задаёт `minimumLegalParents: 1`, одного подтверждённого юридического родителя достаточно.

Проверка после исправления в среде сборки:
- строгая TypeScript-компиляция затронутых production-модулей: успешно;
- отдельные runtime-проверки всех четырёх обнаруженных условий: успешно.

Полный Vitest после исправления в этой среде повторно не запускался: установка зависимостей из npm registry завершилась по тайм-ауту. Просьба выполнить `npm test` и `npm run build` на машине пользователя.
