# OpenWorld RPG 0.11.0 — Высший свет и окружение старта

## Добавлено
- Реестр всех поименованных членов 30 влиятельных домов Ардана.
- Политические структуры всех шести государств без ошибочного сведения их к монархиям.
- Стабильные психологические профили для всех членов домов с подтверждённым статусом жизни.
- Отдельные авторские профили ключевых представителей домов Рейнар, аль-Марун и Северан.
- Стартовые окружения для всех 16 происхождений персонажа; выбранный набор подключается к конкретной кампании.
- Публичные сведения о высшем свете добавлены в индекс знаний ИИ без раскрытия личных секретов и внутренней психологии.
- Тесты полноты реестра, политической модели, стартовых персонажей и корректности расписаний.

## Важные границы
- Высшее духовенство пока не проектировалось — это следующий отдельный этап.
- Выбор игроком династии и включение нового персонажа в родословную пока не подключены к UI.
- Обычный старт остаётся в Ровене; для наследника престола нужна объяснимая причина визита/пребывания в городе.
- Второстепенные дворяне используют устойчивые ролевые психологические архетипы; их индивидуальные биографии и отношения будут углубляться отдельно.

## Проверки
- Проверка TypeScript основных модулей — требуется локальный прогон после установки зависимостей.
- Vitest — требуется локальный прогон.
- `npm audit` — требуется локальный прогон.
