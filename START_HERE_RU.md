# OpenWorld RPG — инструкция перед публикацией

Это текущий рабочий снимок проекта `0.13.0`. Он подготовлен для ручной передачи в GitHub, но не является завершённой игрой и не был опубликован автоматически.

## Как открыть проект

1. Распакуй архив на компьютере или в файловом менеджере телефона.
2. Внутри открой папку `OpenWorld-RPG-0.13.0` — именно в ней лежит `package.json`.
3. Для локального запуска нужен Node.js 20 или новее:

   ```bash
   npm install
   npm run dev
   ```

4. Для проверки и production-сборки:

   ```bash
   npm test
   npm run build
   ```

## Как перенести в GitHub

1. Открой репозиторий `Focro/openWorld`.
2. Перед заменой скачай текущий репозиторий как резервную копию.
3. Открой корень репозитория — там, где находится `package.json`.
4. Скопируй **содержимое** папки `OpenWorld-RPG-0.13.0` в корень репозитория, сохраняя структуру папок `src`, `docs`, `.github` и файлы конфигурации.
5. Подтверди замену совпадающих файлов и добавление новых файлов.
6. Сделай Commit changes в ветку `main`.
7. После запуска GitHub Actions открой вкладку Actions и проверь шаги `npm test` и `npm run build`.

Не загружай папку `node_modules` (её в архиве нет и она не нужна в Git). Не создавай дополнительную вложенную папку `OpenWorld-RPG-0.13.0` внутри репозитория: файлы `package.json`, `index.html`, `src` и `.github` должны оказаться непосредственно в корне репозитория.

## Что уже есть в версии 0.12.0

- Полный исходный проект: React/Vite-интерфейс, игровой движок, Велория, тесты и документация.
- Конструктор назначает процедурную семью для обычных стартовых сценариев; биологические родители, юридическое родительство, опекуны, признание и право наследования хранятся раздельно. Канонические династические факты не должны выдумываться.
- Биологические признаки внешности отделены от изменяемого облика. Стрижка, одежда, загрязнение, раны и шрамы меняются через системные действия.
- Игрок и NPC запоминают внешность только после наблюдения; удалённые персонажи не получают сведения автоматически.
- Сохранения повторно закрепляют биологические признаки при загрузке; предусмотрена совместимость с сохранениями без новых полей.
- Глобальный атлас расширен до 30 поселений и 31 маршрута; у шести государств появились условные контуры. Для 29 поселений кроме Ровена созданы шаблонные локальные карты и по три постоянных NPC; уникальная проработка этих поселений ещё нужна.
- Добавлен слой подготовки знаний для ИИ с источниками, лексическим ранжированием, ограничением объёма и разделением публичной/личной информации NPC.
- Добавлена система личности NPC: пять вручную заданных профилей ключевых жителей Ровена, стабильные ролевые профили для остальных NPC, развивающиеся привычки и связи между персонажами. В 0.12.0 добавлены все 30 дворянских домов, реестр 178 поименованных членов, профили подтверждённо живых дворян и 16 наборов стартового окружения. В контекст также передаются дата, время, профиль героя, ресурсы, доступные выходы и ассортимент магазина. Провайдер ИИ и серверный прокси не подключены.
- Импорт старых ветвящихся сохранений движка 0.4.0 поддерживается через демо-мир.

## Ограничения и статус проверки

- Это незавершённая альфа, а не готовая полноценная игра. Автономные потребности NPC, полноценные болезни и боевая система, автоматические причины смерти, суд, престолонаследие, физические маршруты NPC между городами и серверная защита секретов остаются в плане.
- API ранений и лечения подготовлен, но полноценная боевая/медицинская система ещё не подключена.
- Профили внешности заданы только для ограниченного набора NPC; неизвестные признаки не следует додумывать.
- Высшее духовенство пока не разработано. Из династических ролей подключён только второй принц дома Рейнар; конструктор других наследников, правителей и членов остальных домов остаётся отдельным этапом.
- Три государства Ардана не монархии: Тарвек — выборный конклав, Варент — торговая лига, Элиндор — союз общин. Игрок там может быть наследником дома или выборным кандидатом, но не автоматически принцем.
- Скрытые реестры в открытых исходниках не являются секретными. Не публикуй настоящие тайны мира или API-ключи в клиентский код.
- Зависимости закреплены на Vite 6.4.6 и Vitest 4.1.12; `tinypool` принудительно обновляется до 2.1.2. В этой среде `npm install` завершился по тайм-ауту, поэтому полный `npm test`, `npm audit` и production build после обновления зависимостей не подтверждены. Строгая компиляция TypeScript для production-модулей `src/engine` и `src/worlds` прошла; в 0.12.0 дополнительно проверены модули реестра знати, конструктора и индекса знаний. Новые тесты типизированы с временной декларацией Vitest, но Vitest не запускался в среде подготовки. В исходниках сейчас 22 тестовых файла и 179 тестовых случаев.
- Не используй `npm audit fix --force`: сначала проверь отчёт `npm audit` и совместимость новых версий.

## Дополнение 0.12.0 — второй принц Рейнар

- В конструкторе появился отдельный сценарий «Второй принц дома Рейнар — начать с рождения».
- Кампания начинается в королевской детской Коронхольма в 723 КЛ; возраст героя — 0.
- Биологический отец — Гарен Вальд; мать — куртизанка из далёкой восточной земли, её имя и прежняя жизнь не установлены. Родители не состояли в браке; Гарен признал сына.
- Элиана III — супруга Гарена, не мать героя. Она испытывает к ребёнку устойчивую личную неприязнь из-за измены мужа, но публично соблюдает королевский протокол. В 723 КЛ она ещё принцесса; на престол вступает в 735 КЛ.
- Кронпринц Альдрен родился в 722 КЛ и остаётся первым наследником. Второй принц включён в линию отдельной королевской грамотой после него; признание и право наследования записаны отдельно.
- Внешность фиксирована: светлая кожа, светло-русые прямые волосы, тёмно-карие почти чёрные глаза, выраженные восточноазиатские черты лица. Рост и вес анкеты относятся к новорождённому; распределение характеристик — задатки и потенциал, а не умения младенца.
- Мать присутствует в дворцовой детской при рождении. При достижении двух лет (725 КЛ) её смерть без установленной причины попадает в хронику; NPC больше не появляется в сценах.
- Если игрок выбирает другой сценарий, второй принц появляется в дворцовом окружении как NPC с тем же характером и внешностью.
- Исторический поиск не показывает ещё не родившихся детей и учитывает, что Элиана стала королевой только в 735 КЛ.
